# Quaternius IK Rigged - Windward runtime subset

Imported on 2026-08-12 for Windward's connected sailor prototype.

This directory contains only the runtime mesh and texture subset used by
`res://src/boat/assets/sailor_rig_base.tscn`. The source asset is
**Quaternius IK Rigged with animations**, distributed through the Godot Asset
Library and maintained at:

- https://godotengine.org/asset-library/asset/5235
- https://codeberg.org/jamesonBradfield/Quaternius_IK_Rigged_with_animations
- Original character source: https://quaternius.com/packs/universalbasecharacters.html

Models and animations are by Quaternius. The included asset is released under
CC0 1.0 Universal; see `LICENSE` in this directory. Windward modifies the rig
scene, animation selection, IK targets, first-person rendering, clothing, and
gaze controller locally.
