# Asset provenance notice

Date imported: 2026-08-12 (KST)

Windward uses a reduced subset of the `Quaternius IK Rigged with animations`
Godot asset. The source project supplies the Quaternius Superhero Male skinned
mesh, Skeleton3D hierarchy, textures, IK setup, and base animations. Windward's
runtime scene lives at `res://src/boat/assets/sailor_rig_base.tscn`; seated and
crouched clips are stored beside it.
